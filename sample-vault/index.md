# 记忆库目录索引

## 文件结构

- 📄 `profile.md` — 用户画像（静态信息 + 动态上下文）
- 📄 `CHANGELOG.md` — 所有变更的历史日志
- 📁 `memories/`
  - `tech.md` — 技术栈、工具配置、开发环境
  - `personal.md` — 身份、教育、工作、旅行、社交账号
  - `projects.md` — 项目进展、决策记录、里程碑

## 使用说明

1. 新增分类 → 在 `memories/` 下创建新文件，并更新本索引
2. 跨分类信息 → 写入 `profile.md`
3. 每次写入 → 更新 `CHANGELOG.md`
